# 大都会人寿财富地图 · 客户回馈模型项目

微型纽约地标建筑模型 · 客户忠诚回馈项目展示页面

## 项目介绍

本项目展示了大都会人寿财富地图客户回馈模型的设计方案，包含：

- 项目概览
- 四大核心价值观
- 五种设计方案（A-E）
- 七座纽约标志性地标模型
- 逐级拼装机制展示

## 技术栈

- HTML5
- Tailwind CSS 3
- JavaScript

## 运行方式

```bash
# 本地预览
python -m http.server 8000
# 或使用其他HTTP服务器
```

访问 http://localhost:8000/index.html 查看页面

## 页面结构

```
├── index.html          # 主页面
├── Designs/            # 设计方案图片
├── metindex.html       # 原始项目页面
└── Metdesign.html      # 设计方案页面
```
